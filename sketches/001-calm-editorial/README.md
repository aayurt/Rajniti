## Variant: Calm Editorial

### Design stance
A clean, trustworthy interface prioritizing clarity and approachability for broad audience appeal, inspired by productivity tools like Linear and Notion.

### Key choices
- **Layout:** Traditional header-nav-main-footer structure with clear visual hierarchy
- **Typography:** Inter font system with clear hierarchy (text-sm to text-7xl)
- **Color:** Monochrome base (#1a1a2e) with blue accent (#0066cc) for trust and familiarity
- **Interaction:** Subtle hover states, focus rings, and micro-interactions (button scales, animated counters)

### Trade-offs
- Strong at: Accessibility, readability, professional tone, broad demographic appeal
- Weak at: May feel too conservative for users seeking excitement or novelty

### Best for
- Casual players, families, and users who value reliability over flashiness
- Users coming from traditional board game experiences
- Those prioritizing ease of use and clear information architecture
